Task 4 – Evaluation and Tuning

Overview

This task focuses on evaluating machine learning classification and regression models using different performance metrics and hyperparameter tuning techniques.

Objectives

- Evaluate classifiers using Accuracy, Precision, Recall and F1 Score.
- Generate and interpret confusion matrices.
- Understand why accuracy can be misleading with imbalanced datasets.
- Plot ROC curves and calculate ROC-AUC.
- Identify an appropriate decision threshold to achieve at least 75% recall.
- Perform Random Forest hyperparameter tuning using GridSearchCV.
- Perform XGBoost hyperparameter tuning using RandomizedSearchCV with 15 iterations.
- Evaluate regression performance using MAE, RMSE and R-squared.
- Compare the regression model against a mean baseline.
- Perform final evaluation on the test dataset.

Models Used

Classification

- Logistic Regression
- Random Forest Classifier
- XGBoost Classifier

Regression

- Random Forest Regressor

Hyperparameter Tuning

Random Forest: GridSearchCV with three hyperparameters.

XGBoost: RandomizedSearchCV with 15 iterations.

Evaluation Metrics

Classification:

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
- ROC-AUC

Regression:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

Technologies Used

Conclusion

This task demonstrates model evaluation, performance comparison, decision threshold optimization, hyperparameter tuning and final test evaluation.
