Task 1 - Python Core and Classes

Description

This project demonstrates Python core concepts using employee data.

Concepts Covered

- Functions and Default Arguments
- *args and **kwargs
- Classes and Objects
- Inheritance
- super()
- @property
- Decorators
- For Loop and Conditional Statements
- CSV File Handling

Project Files

- main.py - Python program containing all implementations.
- employees.csv - Employee details and salary data.

How to Run

1. Open the project folder.
2. Open the terminal.
3. Run the following command:

python main.py

Expected Result

The program calculates employee bonuses, displays employee and manager details, and categorizes employee salaries into Low, Medium, and High.
